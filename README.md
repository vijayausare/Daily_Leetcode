# Daily_Leetcode

## Time Complexity
| Input size `n`              | Usually acceptable      | Usually too slow           |
| --------------------------- | ----------------------- | -------------------------- |
| `n ≤ 10`                    | `O(2ⁿ)`, `O(n!)`        | —                          |
| `n ≤ 20`                    | `O(2ⁿ)`                 | `O(n!)`                    |
| `n ≤ 100`                   | `O(n³)`                 | `O(2ⁿ)`                    |
| `n ≤ 1,000` (`10³`)         | `O(n²)`                 | `O(n³)`                    |
| `n ≤ 10,000` (`10⁴`)        | `O(n²)` sometimes       | `O(n³)`                    |
| `n ≤ 100,000` (`10⁵`)       | `O(n log n)`, `O(n)`    | `O(n²)`                    |
| `n ≤ 1,000,000` (`10⁶`)     | `O(n log n)`, `O(n)`    | `O(n²)`                    |
| `n ≤ 10,000,000` (`10⁷`)    | `O(n)`                  | `O(n log n)` may need care |
| `n ≤ 100,000,000` (`10⁸`)   | **`O(n)` or better**    | `O(n log n)`, `O(n²)`      |
| `n ≤ 1,000,000,000` (`10⁹`) | **`O(log n)` / `O(1)`** | `O(n)`                     |
